# 개인정보처리방침 후속 검토 체크리스트

작성일: 2026-10-30

대상: `public/privacy/index.html`의 한국어·영어 방침

공개 페이지에서 제거한 검토 메모를 관리하는 내부 문서입니다. 확인 필요 표시를 제거한 것은 검토 완료 또는 국외 이전이 없다는 확인을 의미하지 않습니다. 확인되지 않은 법인·국가·보유기간은 추정해 기입하지 않습니다.

## 현재 확인 상태

- [x] 카카오: 사용자 제공 앱 연동 검증 결과에 따라 로그인·계정 연결 범위로 정리할 근거가 있음.
- [ ] 카카오: 로그인 범위 확인과 별도로 수신·제공 정보, 처리 역할 및 국외 이전 해당 여부를 정리하고 근거를 기록.
- [ ] Google: 로그인 외 광고·구독 검증·푸시 흐름은 별도 검토 예정. 로그인만 처리한다고 확정하지 않음.
- [ ] Apple: 로그인 외 광고 관련 처리·구독 검증·푸시 흐름은 별도 검토 예정. 로그인만 처리한다고 확정하지 않음.

## Google·Apple의 흐름별 검토

각 항목은 실제 적용 앱 버전과 플랫폼을 기준으로 확인하고, 미사용 기능은 미사용 근거를 기록합니다.

| 흐름 | Google 검토 사항 | Apple 검토 사항 | 결과 반영 위치 |
| --- | --- | --- | --- |
| 소셜로그인 | 요청 권한, 인증 정보 전송 경로, 실제 제공받는 정보와 저장 항목 | 요청 항목, 인증·연결 해제 경로, 실제 제공받는 정보와 저장 항목 | 제1·6·7항 |
| 광고 | iOS AdMob의 실제 동작과 전송 정보, 추적 권한별 차이. Android 광고 SDK·광고 ID 권한 제외 상태 | iOS 광고 추적 권한 요청과 광고 식별자 등 실제 처리 정보. Apple에 직접 전송되는 정보가 있는지 구분 | 제1·5·6·7항 |
| 구독 검증 | Play 구매 토큰·상품·거래 식별자, 검증 요청, 서버 알림 및 중간 처리업체 | App Store 거래·서명 정보, 검증 요청, 서버 알림 및 중간 처리업체 | 제1·6·7·10항 |
| 푸시 | Expo → FCM 경로, 토큰·일반 문구·추가 데이터, 전달 기록 및 보관 | Expo → APNs 경로, 토큰·일반 문구·추가 데이터, 전달 기록 및 보관 | 제1·4·6·7·8항 |

- [ ] 푸시는 일반 알림만 전달하며 자녀 이름·루틴 이름을 포함하지 않는다는 사용자 확인을 실제 payload의 제목·본문·추가 데이터와 대조.
- [ ] 기기 내부에서만 처리하는 정보, 업체에서 제공받는 정보, 회사가 업체에 전송하는 정보를 구분.
- [ ] 로그인·광고·구독·푸시의 계약 주체와 처리 역할을 각각 확인. 동일 브랜드라는 이유로 일괄 분류하지 않음.
- [ ] 앱 코드·서버 함수·운영 설정과 공식 계약·문서로 확인하고, 해결되지 않는 사항만 업체에 문의.

## 국외 이전 고지 보완

- [ ] 실제 국외 이전에 해당하는 흐름을 구분하고 적용 근거 검토.
- [ ] 흐름별 수신 법인명과 연락처 확인.
- [ ] 실제 처리 국가 확인. 법인 소재지와 처리 국가를 구분하며, EU 표기만 있는 로그는 국가 단위 정보 추가 확인.
- [ ] 이전 항목·목적·시기·방법·보유기간 정리.
- [ ] 적용 근거에 맞는 이전 거부 방법·절차·효과 및 고지·동의 방법 정리.
- [ ] Google·Apple·카카오를 한 행에 묶었던 임시 국외 이전 행은 공개 표에서 제거함. 검토 결과에 따라 서비스·흐름별 행으로 다시 반영.
- [ ] 공개 방침의 업체 정책 참조 설명만으로 필요한 고지가 충족되는 것으로 간주하지 않음.

- [ ] Expo: 실제 처리 국가와 푸시 토큰의 보관 종료 조건·시점 확인.
- [ ] Supabase: 글로벌 지원 접근의 수신 법인·국가·보유기간 확인. EU 로그 처리와 구분.
- [ ] Resend: 미국 저장·도쿄 발송의 실제 이전 항목·시기와 적용 근거 확인.
- [ ] 진행 중인 동의 증빙 DB 마이그레이션이 제10항의 기준일·최대 7일 파기 및 백업 처리 설명과 일치하는지 확인.

## 고객지원 이메일과 법령상 별도 보존

- [ ] 고객지원 이메일의 보존 범위 확정: 문의 본문·첨부파일·발신 이메일, 계정·자녀 데이터 삭제 요청, 본인 확인 자료 및 처리 결과를 구분.
- [ ] 유형별 보관 목적과 기간 확정. 문의 종결일·삭제 요청 처리 완료일 등 보관 기간의 기산점도 명시.
- [ ] 계정 삭제 후에도 남는 고객지원 기록이 있다면 보관 항목·사유·기간을 별도로 확정.
- [ ] 이메일함·다운로드한 첨부파일·별도 관리 기록의 파기 시점과 방법을 정하고 실제 처리 절차 확인. Resend 발송 로그의 보관 기간과 고객지원 메일함의 보관 기간을 구분.
- [ ] 법령상 별도 보존 대상의 실제 해당 여부 확인. 해당하는 기록별로 적용 법령·조문, 보존 항목, 기간 및 기산점을 기록.
- [ ] 별도 보존이 필요한 정보의 접근 제한·분리 보관 방식과 기간 종료 후 파기 절차 확정.
- [ ] 해당 근거가 없는 기록에 포괄적인 법정 보존 예외를 추가하지 않음.
- [ ] 확정한 고객지원 기록 및 법정 보존 기준을 개인정보처리방침 제1·10항 등 관련 항목의 한국어·영어에 반영.
